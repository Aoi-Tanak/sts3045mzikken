# Core2 + STS3045M 方向別ステップ補正

`../core2scs0009-high-speed` を元に、ToF段差提示をSTS3045Mへ移植しています。
ノイズは無効です。サーボの実測位置を読み、目標との差を補正します。

## 接続

- Port A: VL53L0X、SDA=GPIO32、SCL=GPIO33。
- Port C: TTL変換回路、TX=GPIO14、RX=GPIO13。
- ID=1、1Mbpsから通信速度を探索、角度サーボモード0。
- 参照元と同じ送信エコーありの回路を想定。エコーなしの場合は `include/config.h` の `kExpectTxEcho=false` にします。

## 目標と補正

原点は位置2048です。起動時はPAUSEで原点への位置指令を送ります。

| 状態 | 実測ステップの目標 | 実測位置の目標 |
|---|---:|---:|
| RUN・有効距離が段差内 | +4 | 2052 |
| 段差外・距離無効・PAUSE | 0 | 2048 |

内蔵振動モーターとタッチの診断結果（`Vib` / `Touch`）は表示のみで、ToF計測や距離に応じたサーボの角度提示を停止しません。
本体の振動モーターは停止を指示し、OFF状態を確認しています。

初期の段差範囲は100mm以上150mm未満です。
`include/config.h` の `kStepHeightCounts=4` は実測ステップの目標です。
段差の目標が切り替わったとき、100ms周期で取得する最新の実測ステップAと補正前の目標Tを比較します。

- T > A: T + 5を指令します。
- T < A: T - 3を指令します。
- T == A: 直前の指令を保持します。

例えば実測位置2048から目標2052へ進む場合は2057を指令し、実測位置2052から目標2048へ戻る場合は2045を指令します。
段差の目標は原点から+4または0に固定し、補正値を累積しません。
方向補正量は `include/config.h` の `kPositiveOffsetCounts=5`（増加方向）、`kNegativeOffsetCounts=3`（減少方向）です。

実測取得・画面更新はともに100ms周期です。
方向補正は段差目標の切り替わり・接続後・B単押し時に一度だけ計算し、その指令を保持します。
動作途中に実測が目標をまたいでも、自動的に逆方向の補正を送り直すことはありません。
以前の1カウントずつの追加補正、3回一致判定、5秒の調整タイムアウトは廃止しました。
不感帯・負荷などにより、実測値が目標に一致するかは実機で確認してください。
画面の `Target` は目標、`Actual` は原点からの実測ステップ数です。
通信異常時は `Actual: --- steps` にし、約1秒間隔で再接続します。
再接続後は原点を指令してから、その時点の目標に方向別補正を適用します。
速度・加速度は最大設定（0）を引き継いでいます。
サーボ側の角度制限が原点±40カウントを許容することを接続時に確認します。
EEPROMや不感帯設定は変更しません。

## 操作

| ボタン | 単押し | 800ms長押し |
|---|---|---|
| A | なし | RUN / PAUSE |
| B | 実測値から方向補正を再適用 | なし |
| C | 段差位置をランダム変更 | 段差幅1～5cm切り替え |

USBシリアル: `b` 補正を再適用、`w` 幅、`r` ランダム位置、`[` / `]` 位置−/+10mm、`?` ヘルプ。
旧ノイズ用の `n` / `a` は無効です。

## ビルドと実機確認

`pio run` でビルド、`pio run -t upload` で書き込みます。

1. 起動時にTarget=0となり、Actualが原点との差を表示することを確認。
2. A長押しでRUNにして距離120mmを提示し、Target=+4を確認。実測が目標より小さい場合、シリアルログでsent=9、position=2057を確認し、Actualの変化を観察。
3. 距離を段差外にするかPAUSEにし、Target=0を確認。実測が目標より大きい場合、sent=-3、position=2045を確認し、Actualの変化を観察。
4. 目標が変わらない間は指令が繰り返し補正されないこと、B単押しで再適用すること、通信断時に `---` になることを確認。
